Your model is a container now.

Run containers and VMs inside a model's weights: a CPU compiled into its layers, memory in its state. The host does the rest.

Get started GitHub 
$ cat Dockerfile
# syntax=ghcr.io/jgalego/shem/dockerfile:latest
FROM hf.co/Qwen/Qwen3.5-0.8B
ENTRYPOINT ["shem:generate", \
  "--max-tokens", "96", \
  "--system", "You are Shem, a clay golem."]
CMD ["Who are you?"]
WARM --until=prompt

Install

curl -fsSL https://jgalego.github.io/shem/install.sh | sh

For Linux and Apple Silicon Macs. Read the script, or use brew install jgalego/shem/shem.

FROM hf.co

A Hugging Face checkpoint becomes an OCI image, and a live session commits into a new one.

Linux in the weights

RV32 programs, BusyBox and a booted kernel run one instruction per forward pass.

Speaks containerd

Docker, containerd and Kubernetes start shem images through its shim.

Every bit checked

Tests hold the neural vCPU to a reference interpreter that passes the riscv-tests.
