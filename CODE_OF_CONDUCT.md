# Code of Conduct

shem follows the [CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). It applies in the repository, its issues and pull requests, and anywhere else the project is represented.

To report a violation, use GitHub's [private vulnerability form](https://github.com/JGalego/shem/security/advisories/new) and say it is a conduct report, or contact a maintainer listed in [MAINTAINERS.md](MAINTAINERS.md) directly. Reports are kept confidential.
